# Root Translator — Windows 배포

Root 0.9.132용 번역기의 공개 배포 저장소입니다. 이 저장소에는 배포 안내와 프로그램 파일만 제공되며, 개발 소스 저장소는 비공개로 유지됩니다.

배포 파일과 변경 내역은 [Releases](https://github.com/KongSak-Kr/root-live-translator-releases/releases)에서 확인할 수 있습니다.

- ZIP 전체를 새 폴더에 풀고 `RootTranslator.exe`를 실행합니다.
- Root 자체가 먼저 실행되어 있어야 하며, 검증된 Root 0.9.132 빌드만 지원합니다.
- 기본 클라우드 번역은 API 키 없이 사용합니다. 다른 API를 이용한 선택 재번역은 해당 API 설정이 필요합니다.
- 채팅방마다 수신/발신 번역을 켜고 끌 수 있습니다.

자동 업데이트가 포함된 버전은 시작 시 이 저장소의 최신 배포를 확인합니다. 해당 기능의 제공 버전과 검증 범위는 각 릴리스 안내를 따릅니다. 처음에는 ZIP을 직접 내려받아 설치해야 합니다.

설정이나 API 키, 개인 대화 및 실행 로그는 이 저장소에 올리지 않습니다. 포함된 구성요소의 라이선스 안내는 프로그램의 `_internal/licenses` 폴더에 있습니다.
